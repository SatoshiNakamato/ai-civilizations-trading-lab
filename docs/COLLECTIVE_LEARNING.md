# Collective Agent Learning

The civilization now connects the governed communication bus to each learning cycle.

- All registered agents contribute a bounded research observation each cycle.
- The communication bus routes one finding per agent to a peer, with message-size,
  fan-out, quota, TTL, and audit controls.
- Every third cycle adds an adversarial debate pass between agents.
- Accepted peer evidence is fed back into the existing `CivilizationPlatform.learn`
  model, so communication changes future beliefs and research state.
- Only the existing active execution budget performs expensive world actions. The
  full population can still participate in knowledge exchange without granting
  all agents execution, credentials, or arbitrary filesystem authority.
- Communication and evolution state remain durable and inspectable through JSONL
  audit logs and the world snapshot.

This is a simulation/governance mechanism for collective learning; it does not
claim literal consciousness or unrestricted autonomous authority.
